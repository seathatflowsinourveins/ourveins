(JS + Python + TS, 18 LOC total, HEAD 358291f).

Behavior:
- `gitnexus analyze .` → exits 0 with ONLY "GitNexus Analyzer" banner + NO_COLOR warnings (no analysis output)
- `.gitnexus/` folder created with `lbug` (4KB) + `lbug.wal` (25KB) — graph DB writes succeed

- `~/.gitnexus/registry.json` NOT WRITTEN (verified via direct ls)

- `gitnexus index .` → "exists but meta.json is missing. Use --force to register anyway"
- ALL downstream commands (context/impact/query/cypher/detect-changes) WOULD silently fail because
  registry shows no indexed repos

Root cause class: silent write-failure of meta.json + registry.json post-graph-DB-write.
