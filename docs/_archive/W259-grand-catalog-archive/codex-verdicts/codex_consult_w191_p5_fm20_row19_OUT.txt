## When this rule applies

ANY of these triggers fires this rule:

1. Agent return contains multi-clause prescription (3+ independent claims that could be sub-decomposed)
2. Orchestrator-side synthesis cites a prior agent verdict / memory file / task tracking text VERBATIM in next-fire brief
3. Next-fire brief carries claim X without explicit `[VERIFIED via <probe>]` marker per `cross-model-consensus.md §Evidence marker discipline` MUST-USE convention
4. Cross-fire propagation suspected: claim X originated 1-3 fires back; no runtime probe at any hop boundary

## How to apply (forward-only convention)

When an agent return contains multi-clause prescriptions:

1. **Decompose by sub-claim** — break the agent's "X+Y+Z" return into 3 independent claims; each gets its own probe shape per `synthesis-layer-verify.md §Subclaim-type discriminator` (UPSTREAM/OPERATIONAL/CATEGORY)
2. **Mia-probe each sub-claim INDEPENDENTLY at synthesis time** — do NOT cite X verbatim into the next-fire brief without runtime probe
3. **Cite the probe outcome verbatim in synthesis** — "Agent A claim X1: VERIFIED via `Grep`; X2: REFUTED via `Read file:line`; X3: PENDING-PROBE"
4. **Refuted sub-claims DROPPED from next-fire brief** — do not propagate
5. **At next-fire dispatch**: brief cites only verified sub-claims + explicit `[VERIFIED via <probe>]` markers per `cross-model-consensus.md §Evidence marker discipline` MUST-USE convention codified iter-107

## Recovery actions when FM-20 fires

When current-fire Mia probe surfaces propagated OVER from N-fires-back:

1. **DROP refuted sub-claim from current fire's apply scope**
2. **Document refutation in commit body** with `[VERIFIED via <probe>]` cite-trail
3. **Pivot ship to verified-surviving prescriptions** OR HONEST-NON-FINDING if all sub-claims refuted (per `synthesis-layer-verify.md §Reporting categories`)
4. **Trace cite-propagation backward** through prior synthesis docs to find the originating agent claim (helps ladder-tracking)
5. **Forward-only correction** per `port-note-discipline.md §6` — do NOT rewrite historical commit bodies; correct the LIVE state and codify forward

## Anti-patterns

- **Cite agent claim verbatim into next-fire brief without sub-claim Mia probe** — refuted by n=5 cumulative cross-arc evidence. Agent confidence ≥0.85 does NOT correlate with sub-claim accuracy. Each sub-claim needs its own probe.
- **Synthesize first, probe later** — refuted by Wave 19 fire-22 evidence: orchestrator-side synthesis-Mia caught D2 + C OVER claims AFTER agent return but BEFORE fire-23 dispatch (3-OVER catch documented at commit `d2a765e` body). The probe-at-synthesis catches before propagation hop 2; without it, the OVER reaches next agent's dispatch context.
- **Treat task-tracking text as authoritative for source-of-truth claims** — refuted by Wave 37 AGENTS.md catch. Task tracking text (e.g., "GAP CONFIRMED ~170 LOC draft ready" in task #512) records state AT WRITE-TIME; subsequent ship-completion commits close gaps but task text doesn't auto-update. Per `evidence-policy.md` Marker Decay corollary.
- **Treat HONEST-NON-FINDING as agent failure** — per `synthesis-layer-verify.md §Reporting categories` HNF distinction. An agent that probes its own claim and self-refutes (Agent A fire-22 ccusage self-catch; Agent A Wave 37 reverse-Mia AGENTS.md+context7) is the highest-quality return shape — preserve as evidence, do not re-spawn.
- **Skip the recursive-OVER probe at synthesis layer** — refuted by Wave 19 fire-22 close: synthesis-Mia caught 3 OVER claims that would have shipped if I'd cited Agent D2's "graphify NEW" verbatim into fire-23 brief. The probe budget is cheap (1-3s) vs revert cost (5-15 min).
