# Audit dimensions

## AXIS-A1: Hotspot scoring (top-20 files)
Per-file score = commits_last_90d × unique_authors × recent_fix_density. Query:
- `git log --since='90 days ago' --pretty=oneline -- <file> | wc -l` for commit count
- `git log --pretty=format:'%an' --since='90 days ago' -- <file> | sort -u | wc -l` for unique authors
- `git log --grep='fix\|bug\|hotfix\|patch\|revert' --oneline --since='30 days ago' -- <file> | wc -l` for recent fix density

Scope: .claude/**/*.{md,py,sh,json} + tools/**/*.ps1 + scripts/**/*.py + CLAUDE*.md + docs/*.md

## AXIS-A2: Bus-factor analysis (top-20 by single-author%)
Per top-20 hotspot file: % commits by single most-active author. >70% = HIGH bus-factor risk.

## AXIS-A3: Bug-magnet scoring (top-20 by fix-commit ratio)
Per top-20 hotspot file: (fix/bug/hotfix commits / total commits) over last 180 days. >40% = HIGH bug-magnet.

## AXIS-A4: Pre-edit recommendations
For each HIGH-risk hotspot (hotspot score OR bus-factor OR bug-magnet): recommend pre-edit verification protocol (test coverage / smoke probe / Mia pre-apply discipline).
