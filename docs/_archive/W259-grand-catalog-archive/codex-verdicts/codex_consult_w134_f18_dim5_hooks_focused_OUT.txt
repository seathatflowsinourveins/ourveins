210-# Reference: `https://resources.anthropic.com/2026-agentic-coding-trends-report` (TIER-1 Anthropic; full PDF at `https://resources.anthropic.com/hubfs/2026%20Agentic%20Coding%20Trends%20Report.pdf`) [VERIFIED 2026-05-03 via Wave-6 Agent M perplexity_research [17][31][48]] — Anthropic 2026 Agentic Coding Trends Report identifies risk-stratified gating as the SOTA pattern for AI-agent code change verification: low-risk = full-agent-delegate + post-commit review; medium-risk = pre-commit human review (agent implements, human approves); high-risk = design review BEFORE agent implements.

73-
74-Per code.claude.com/docs/en/hooks verbatim: **"`asyncRewake: true` Runs in background and wakes Claude on exit code 2. Implies `async: true`. Stderr (or stdout if empty) shown as system reminder."**
