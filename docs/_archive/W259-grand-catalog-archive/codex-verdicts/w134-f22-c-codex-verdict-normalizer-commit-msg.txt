## What ships

### `tools/codex_verdict_normalizer.py` (~205 LOC)

Unifies the bifurcated codex verdict architecture into a single normalized JSONL summary
stream. Scans `.claude/state/codex_review_HEAD_*.txt` JSON verdicts → writes normalized
records to `.claude/state/codex_verdict_summary.jsonl` (gitignored — operator-state-outside-repo).

**Normalized record shape** (one per verdict file):
```json
{
  "ts": "<ISO 8601 mtime>",
  "sha": "<sha8 from filename>",
  "verdict": "approve|needs-attention",
  "summary": "<1-line up to 200 chars>",
  "findings_count": <int>,
  "severity_dist": {"critical": 0, "high": 0, "medium": 0, "low": 0},
  "max_severity": "critical|high|medium|low|null",
  "max_confidence": <float|null>,
  "source_file": "codex_review_HEAD_<sha8>.txt"
}
```

**Modes**:
- Full scan (default): re-walks all verdicts, dedupes by (source_file, ts) composite key
- `--incremental`: only files newer than latest summary ts (faster on re-runs)
- `--dry-run`: prints would-append records to stdout (no JSONL write)

> "Key existing records by stable source identity plus version, e.g. source_file + ts or
> source_file + content digest, while still retaining sha as a query field"
> "Skip only when the current source version is already present"

**Applied changes** (this commit, same file):

1. `load_existing_summary()` return type changed from `dict[str, dict]` keyed by `sha`
   → `dict[tuple[str, str], dict]` keyed by `(source_file, ts)` composite. Distinct
   re-reviews of same HEAD now preserve as separate records.

2. Skip logic at line 182:
   ```python
   # Before (sha-only):
   sha = rec["sha"]
   if sha in existing and not incremental: skipped_existing += 1; continue

   # After (composite (source_file, ts) per codex T1 prescription):
   composite = (rec["source_file"], rec["ts"])
   if composite in existing and not incremental: skipped_existing += 1; continue
   ```

Same SHA + same mtime → skipped (truly idempotent re-scan).
Same SHA + new mtime (re-review of same HEAD) → NEW record appended (verdict update preserved).
