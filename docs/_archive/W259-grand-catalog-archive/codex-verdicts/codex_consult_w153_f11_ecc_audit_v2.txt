### Q2: Top-N high-leverage ECC skills

If 182 canonical skills are confirmed actually-loaded:

- Which DUPLICATE functionality already in superpowers / addy-agent-skills / context-mode / other enabled plugins (KISS Must-Never #4)?

### Q3: CR-12 disposition class per ECC skill

For each of 182 canonical ECC skills, apply CR-12 6-class lattice:
- GENUINELY-NEW: novel functionality
- DUPLICATE-FUNCTIONALITY: duplicates another loaded plugin (REJECT-FOR-FIT)
- PARTIAL-OVERLAP: shares scope but different mechanism (case-by-case)
- ECOSYSTEM-IMPORT: brings unrelated framework
- CITE-CLASS-CANONICAL: reference material
- PROVIDER-COMPLEMENT: parallel-mechanism (both useful)

### Q4: Disable mechanism if action needed

If F11 finds disable candidates:
- Per-skill: NOT supported by Anthropic CC (plugin-level enable/disable only; no per-skill granularity per docs)
- Per-plugin: would require disabling ECC entirely (NOT recommended — too many useful skills)
- Selective: fork ECC + remove unwanted skills? (CR-9 fork-bleed risk per `port-note-discipline.md §6` — sibling-clone modifications)
- DEFER: cite-only audit; no action until Anthropic ships per-skill granularity
