**Shared helper** added to `_observation_writer.py` after L72 (`now_iso`):

```python
def merge_agent_context(record: dict, payload: dict | None) -> dict:
    """Merge agent_id + agent_type from stdin payload into a JSONL record.

    Per Z:/repos/deps/claude-agent-sdk-python/src/claude_agent_sdk/types.py:246-262
    @ HEAD b512f256 _SubagentContextMixin: tool-lifecycle hook inputs carry
    agent_id (str) + agent_type (str) at top level. Persisting them in JSONL
    audit rows enables parallel-sub-agent attribution per audit-action-loop.md
    §Hook telemetry contract.

    Returns a shallow copy of record with agent_id/agent_type added when
    payload provides them. If payload is None or missing the fields, the
    record passes through unchanged (main-session writes have no agent_id).

    Idempotent: callers that already populate agent_id/agent_type are not
    overwritten when payload also has them — the existing record value wins.
    """
    if not isinstance(payload, dict):
        return record
    merged = dict(record)
    if "agent_id" not in merged:
        ai = payload.get("agent_id")
        if ai is not None:
            merged["agent_id"] = ai
    if "agent_type" not in merged:
        at = payload.get("agent_type")
        if at is not None:
            merged["agent_type"] = at
    return merged
```
