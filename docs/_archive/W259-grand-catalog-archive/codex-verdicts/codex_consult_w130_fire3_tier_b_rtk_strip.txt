## Root cause (Tier-B)

`Z:/claude-sota-installed/.claude/hooks/scripts/_guard_base.py:336-394` — `git_verb_matches`:

```python
def git_verb_matches(cmd: str, verb: str) -> bool:
    import shlex
    if not cmd or not isinstance(cmd, str):
        return False
    for seg in re.split(r"\s*(?:&&|\|\||;)\s*", cmd.strip()):
        seg = seg.strip()
        if not seg.startswith("git "):    # ← REJECTS "rtk git ..." segments
            continue
        try:
            parts = shlex.split(seg, posix=True)
        except ValueError:
            parts = seg.split()
        if not parts or parts[0] != "git":  # ← Defense-in-depth
            continue
        idx = 1
        while idx < len(parts):
            tok = parts[idx]
            if tok in _GIT_FLAGS_VALUE:
                idx += 2
                continue
            if tok in _GIT_FLAGS_NOVALUE:
                idx += 1
                continue
            if tok.startswith("--") and "=" in tok:
                idx += 1
                continue
            return tok == verb  # First non-flag token == verb
    return False
```

For cmd `rtk git -C path add -- file && rtk git -C path commit -o file -F msg`:
- Split on `&&` → 2 segments
- Segment 1: `rtk git -C path add -- file` → `seg.startswith("git ")` is False → SKIP
- Segment 2: `rtk git -C path commit -o file -F msg` → `seg.startswith("git ")` is False → SKIP
- Returns False → `_is_commit_cmd` False → `filter_rejected_not_commit`

## Proposed Tier-B fix

Strip leading `rtk ` (RTK 0.39.0 PreToolUse:Bash auto-rewrite per Wave 118 Ship A2 commit `741d695`) before the `seg.startswith("git ")` check:

```python
RTK_PREFIX = "rtk "  # Wave 118 Ship A2 RTK auto-rewrite via CC hookSpecificOutput.updatedInput.command

for seg in re.split(r"\s*(?:&&|\|\||;)\s*", cmd.strip()):
    seg = seg.strip()
    # Strip RTK wrapper (CC PreToolUse:Bash hook prepends "rtk " per
    # `.claude/settings.json` PreToolUse[6][6] rtk.exe hook claude entry)
    if seg.startswith(RTK_PREFIX):
        seg = seg[len(RTK_PREFIX):].lstrip()
    if not seg.startswith("git "):
        continue
    # ... rest unchanged
```

Edge cases:
- `rtk git -C path commit ...` → strip → `git -C path commit ...` → matches → ✓
- `git commit ...` (no rtk) → no strip → matches → ✓ (preserves existing behavior)
- `rtk someothercmd ...` → strip → `someothercmd ...` → no `git ` prefix → SKIP → ✓
- `rtkrtk git ...` (no space after first rtk) → no strip (doesn't start with `rtk `) → no `git ` prefix → SKIP → ✓
- `rtk-foo` (rtk-hyphen-foo) → no strip → no `git ` prefix → SKIP → ✓
