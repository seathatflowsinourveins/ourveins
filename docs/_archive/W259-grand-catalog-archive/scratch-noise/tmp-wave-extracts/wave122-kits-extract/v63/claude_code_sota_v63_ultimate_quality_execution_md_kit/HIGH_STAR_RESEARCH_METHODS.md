# High-star research methods

## Research method

```text
1. Scan high-star topic pages:
   claude-code
   claude-code-skills
   token-optimization
   llm-evaluation
   ai-agents
   mcp
   codex-cli

2. Cross-check official docs:
   Claude Code commands/costs/skills/worktrees/Agent SDK
   Codex models/best practices/AGENTS.md/Skills/plugin

3. Classify every candidate:
   default
   selective
   reference-only
   audit-required
   discovery-only
   cut

4. Keep only if it improves:
   context control
   semantic retrieval
   read-path compression
   worktree isolation
   workflow state
   independent review
   quality/security gates
   benchmark/eval feedback
   source auditability

5. Demote:
   broad marketplaces
   prompt packs
   memory tools without retention model
   dashboards without worktrees/diffs
   bridges except official plugin
   leaked/unofficial internals
   system-prompt mutators unless audited
```
