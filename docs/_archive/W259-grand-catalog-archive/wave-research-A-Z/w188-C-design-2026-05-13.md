## Requirements (10 mandatory + 1 HONEST-NON-FINDING)

1. **Stagger**: 8-account round-robin; 7.5min sleep between probes (8 × 7.5 = 60min full cycle); respects 1-call/hour Anthropic rate limit
2. **Auth file iteration**: glob `.cli-proxy-api/claude-*.json` (exclude `antigravity-*` / `codex-*` / `gemini-*`); per-account state JSON
3. **Adaptive backoff**: parse 429 Retry-After header; replan next probe AFTER reset_at; cross-sibling propagation (any account 429 → blocks family for 10min per Aperant L2200-2216)
4. **Persist schema**: one JSONL line per probe to `.claude/state/cpa_oauth_quota.jsonl`
5. **Daemon mode** + **tick mode**: BOTH supported via `--daemon` flag (long-running) OR `--tick` (Windows Task Scheduler / eee.ps1 cron-loop friendly)
6. **Idempotent re-entry**: `--tick` reads state.json, picks oldest-probed account where (now > retry_after_unblock_ts), probes ONE then exits
7. **Mgmt key**: read from `Z:/claude-sota-installed-state/cliproxy-mgmt-secret.txt` (NEVER hardcode) — RESERVED for Path B fix-forward
8. **Timeout**: per-request 30s; total tick budget 60s
9. **Logging**: stderr only on errors; stdout JSON summary on success for SessionStart consumption
10. **Mia-pre-apply compatibility**: `--probe-only` dry-run mode emits payload structure without firing requests

**HONEST-NON-FINDING** (per `synthesis-layer-verify.md §Reporting categories`): CPA `POST /v0/management/api-call` exact request schema for passing through `/api/oauth/usage` was NOT fully verified during design phase — Aperant calls Anthropic directly with bearer token (NOT via CPA). Two paths exist:
- **Path A**: bypass CPA, call `https://api.anthropic.com/api/oauth/usage` directly with bearer = `access_token` from auth file
- **Path B**: route through CPA `POST /v0/management/api-call` per W187 §6.1 to preserve rate-limit-header response

**Design decision**: Path A (direct-to-Anthropic) — matches Aperant pattern exactly; CPA routing adds latency + uncertainty about endpoint schema. Path B reserved as fix-forward if Path A surfaces unexpected header-stripping.

## Mechanism

```
[--tick mode (preferred; Windows Task Scheduler / cron-loop friendly)]
  1. Load state.json (per-account last_probe_ts + retry_after_unblock_ts)
  2. Glob .cli-proxy-api/claude-*.json (exclude non-Anthropic prefixes)
  3. Filter accounts where (now > retry_after_unblock_ts)
  4. Sort by (last_probe_ts ASC) — oldest first
  5. Pick TOP-1; if none eligible, exit 0 (silent skip)
  6. Read access_token from auth file
  7. HTTP GET https://api.anthropic.com/api/oauth/usage
     Headers: Authorization: Bearer <access_token>
              anthropic-beta: oauth-2025-04-20 (per Aperant default)
  8. Parse response:
     - 200 → normalize per Aperant L2396-2411 (new nested OR legacy flat)
            → append to cpa_oauth_quota.jsonl
            → update state.json: last_probe_ts=now, retry_after_unblock_ts=now+3600
     - 429 → parse Retry-After header (seconds OR HTTP-date)
            → update state.json: retry_after_unblock_ts=now+retry_after
            → propagate to all sibling accounts (set retry_after_unblock_ts=now+600 for siblings per Aperant L2200-2216)
            → append 429 record to jsonl
     - 401/403 → mark account auth-fail; do NOT retry-loop; emit stderr
     - other → record failure timestamp; cooldown retry after API_FAILURE_COOLDOWN_MS (60s)
  9. Atomic write state.json via tempfile+rename
  10. Atomic append jsonl via _atomic_jsonl_append helper (existing in scripts/)
  11. Emit stdout JSON summary: {account, status_code, five_hour_pct, seven_day_pct, ts}
  12. Exit 0

[--daemon mode (long-running)]
  while True:
    invoke --tick logic
    sleep 7.5 * 60 = 450s
```

## Failure modes

| Failure | Detection | Recovery |
|---------|-----------|----------|
| Auth file missing/malformed | `json.JSONDecodeError` | Skip account; log stderr |
| 429 rate limit | `response.status_code == 429` | Parse Retry-After; cross-sibling propagate (10min); exit 0 silent |
| 401/403 auth fail | `response.status_code in (401, 403)` | Mark account; emit stderr; do NOT retry loop |
| Timeout | `socket.timeout` after 30s | Record failure; 60s cooldown |
| State corruption | `json.JSONDecodeError` on state.json | Fresh start (recreate empty state); log stderr |
| Anthropic API down | `urllib.error.URLError` connection refused | Record failure; 60s cooldown; exit 1 |
