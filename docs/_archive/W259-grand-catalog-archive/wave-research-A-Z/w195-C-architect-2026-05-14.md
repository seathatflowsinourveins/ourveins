## Task 1 — CR-12 6-class disposition lattice METHODOLOGY (~120 LOC)

### Adversarial review protocol (3-axis weighted scoring rubric)

Given Agent A's Top-3 ADOPT-NOW recommendations, classify each into one of CR-12's 6 classes
(GENUINELY-NEW / DUPLICATE-FUNCTIONALITY / PARTIAL-OVERLAP / PROVIDER-COMPLEMENT / ECOSYSTEM-IMPORT /
CITE-CLASS-CANONICAL) via:

**Axis 1 — Probe-DAG-7 (Z:/claude-sota-installed/.claude/rules/ahfv-probe-dag.md)** — weight 50%

| Probe | Failure → Class |
|---|---|
| P1 count-OVER | Refutes ADOPT premise → DEFER (not class assignment) |
| P2 SDK-vs-CLI surface mismatch | Probe 5 sub-class → DEFER |
| P3 architectural-API mismatch | PROVIDER-COMPLEMENT eligible |
| P4 plugin-namespace duplicate | DUPLICATE-FUNCTIONALITY (REJECT-FOR-FIT) |
| P5 mode-harness-shape (HARD-GATE / interactive setup) | REJECT-FOR-FIT |
| P6 LICENSE/registry blocker | per SRA D1 use-class precision; AGPL CLI = OK, library-link = REJECT |
| P7.a demand-absence | REJECT-FOR-FIT |
| P7.b demand-creates-new-workflow + 5-clause check | GENUINELY-NEW OR PARTIAL-OVERLAP |

**Axis 2 — convergence-gate Axis-1+2+3 (Z:/claude-sota-installed/.claude/rules/convergence-gate.md)** — weight 30%

| Axis | Threshold | Adjustment |
|---|---|---|
| Axis 1 ≥3 distinct orgs | PASS at firm OR via STRONG-PROVENANCE-EXPRESS | +0.30 |
| Axis 2 ≥2 named-T2 dated artifact | PASS firm | +0.20 |
| Axis 3 cpd × age band | STABLE-BURN-IN OR sustained-active | +0.10; FRESH-PAINT = -0.40 |

**Axis 3 — SRA D1-D10 (Z:/claude-sota-installed/.claude/rules/sota-research-architecture.md)** — weight 20%

Score per dimension PASS/FAIL; threshold ≥7/10 with no critical (D1 license-use-class blocking OR
D6 use-class incompatible) FAILED. SRA verdict thresholds: 9-10 INSTALL / 7-8 DOWNGRADE-WITH-DISCLOSURE /
5-6 DEFER / <5 REJECT.

**Composite score** = 0.50×Probe-DAG + 0.30×convergence-gate + 0.20×SRA. Maps to class:
- ≥0.85 + GENUINELY-NEW evidence → **INSTALL** (CR-12 PRIMARY path per official-native-channel)
- 0.70-0.85 + PARTIAL-OVERLAP/PROVIDER-COMPLEMENT → **CITE-IMPORT** (research-input only OR adopt-as-
  ALTERNATIVE not PRIMARY)
- 0.55-0.70 OR demand uncertain → **DEFER** (queue Probe DAG re-fire next-wave)
- <0.55 OR D1/D6 critical FAIL → **REJECT** (refuted by axis-blocker)

### Decision tree

```
ADOPT-NOW candidate from Agent A
  ↓
Step 1: Probe-DAG-7 (axis 1)
  ├─ P4 plugin-namespace duplicate? → DUPLICATE-FUNCTIONALITY → REJECT
  ├─ P5 HARD-GATE / interactive setup? → REJECT-FOR-FIT → REJECT
  ├─ P6 LICENSE blocker (SRA D1 use-class)? → REJECT (CRITICAL FAIL)
  ├─ P7.a demand-absence? → REJECT
  └─ All PASS → Step 2
  ↓
Step 2: convergence-gate Axis-1+2+3 (axis 2)
  ├─ Axis 1 <3 distinct orgs? → DEFER (re-fire Wave-N+1 with multi-source crawl)
  ├─ Axis 3 FRESH-PAINT (<30d + squashed-history)? → DEFER (90-day burn-in)
  └─ All PASS → Step 3
  ↓
Step 3: CR-12 6-class assignment via mechanism comparison
  ├─ No incumbent parallel → GENUINELY-NEW → INSTALL via CR-6 official-native-channel
  ├─ Full parallel + same mechanism → DUPLICATE-FUNCTIONALITY → REJECT
  ├─ Overlap + different mechanism → PARTIAL-OVERLAP → CITE-PATTERN-ONLY OR STUDY-PILOT-PATTERN-EXTRACT
  ├─ Parallel API + different scope → PROVIDER-COMPLEMENT → INSTALL-as-ALTERNATIVE
  ├─ Novel primitive + heavy ecosystem → ECOSYSTEM-IMPORT → CITE-PATTERN-ONLY (typical)
  └─ Anthropic OFFICIAL educational/reference → CITE-CLASS-CANONICAL → ACCEPT-AS-CITE-REFERENCE
```

### Anti-patterns (what makes adversarial review FAIL)

1. **Retroactive-convergence-manufacturing** — building evidence AFTER picking verdict.
   Defense: synthesis-layer-verify.md axis-9 decompose-before-flip. Mia-probe EACH sub-claim BEFORE
   verdict assignment, not after.

2. **Single-cohort discovery bias** — auditing Agent A's set without ≥2-cohort fan-out per CLAUDE.md
   §SOTA Repository Discovery L99-110 9-cohort menu. Required: C1 GraphQL star+topic + at least one
   other cohort (C5 named-author / C6 awesome-list / C9 stars-sorted-direct).

3. **CITE-CLASS-CANONICAL conflation with PROVIDER-COMPLEMENT** — both have parallel cite-anchors.
   Discriminator per CR-12 L55: "is the object itself install-class artifact or reference material?"
   Misclassification → wrong disposition (install runtime artifact when ratify-as-cite is correct).

4. **STAND-IN verdict ratified without cross-model gate** — Sonnet-stand-in adversarial review of
   Sonnet-stand-in Agent A return = SAME-MODEL audit. Cross-model gate REQUIRED per CR-3 + SRA
   §"Cross-model T1 verification mandate". Defense: arc-level satisfaction via Agent B BRIDGE-MODE
   REAL GPT-5.5 OR Path P codex exec foreground+tee per cmc-t1-t7-lifecycle.md §"On codex unavailable".

5. **Probe-DAG SHORT-CIRCUIT** — skipping P4-P7 because "the upstream repo is local". Local-clone-
   existence ≠ ship-readiness. Plugin-namespace probe MUST fire BEFORE vendoring (kiss-dry-yagni
   Must-Never #4).

6. **Score-threshold abuse** — choosing thresholds that round to desired verdict. Defense: publish
   the 3-axis weighted score BEFORE the verdict (write rubric → calculate → verdict; not verdict →
   justify rubric).
