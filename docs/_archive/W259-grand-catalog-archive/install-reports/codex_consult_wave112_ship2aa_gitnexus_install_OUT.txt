20: ## The rule
21: A new pattern, repo, SDK, or external primitive is ADOPT-NOW only when CONVERGENCE evidence is present. Convergence means the pattern exists independently in multiple authoritative places, not just one. Absent convergence, the default verdict is **REJECT-until-convergence** — not STUDY-PILOT, not "maybe later."
22: 
23: This gate stacks ABOVE the `.claude/skills/sota-research/SKILL.md` 5-row LOAD-BEARING bar (LOCAL — sota-research skill present at `.claude/skills/sota-research/SKILL.md`). It is stricter: the 5-row bar allows STUDY-PILOT on any `[UNKNOWN]`; the convergence gate does not — any missing convergence axis is a REJECT until that axis is satisfied OR the STRONG-PROVENANCE-EXPRESS predicate fires.
