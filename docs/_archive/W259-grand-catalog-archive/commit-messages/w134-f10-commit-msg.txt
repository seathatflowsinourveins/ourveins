## GraphQL methodology (file 01)

Per user directive — codified reusable GitHub GraphQL probing pattern:
1. Direct repo metadata batch via `gh api graphql -f query='query { r0: repository(...) { ... } r1: repository(...) { ... } ... }'`
2. Search-based recovery via `gh api graphql -f query='query($q: String!) { search(query: $q, type: REPOSITORY, first: 5) { nodes { ... on Repository { ... } } } }'`
3. Recovery scoring rubric (5-criterion: name-match / owner-match / description-match / activity / stars-magnitude)
4. Authenticated via `GITHUB_TOKEN` (5000 points/h budget; negligible cost per query)

Reusable as future `gh-graphql-repo-resolver` eee skill (Fire 11 candidate).
