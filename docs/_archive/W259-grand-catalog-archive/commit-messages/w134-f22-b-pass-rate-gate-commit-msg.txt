## What ships

### `evals/evolve_pass_rate_gate.py` (~195 LOC)

Multi-source eval pass-rate gate with bootstrap-baseline workflow:

**Signal sources** (priority order):
1. **codex review verdicts** (PRIMARY — implemented) — parses last N (default 20)
   `.claude/state/codex_review_HEAD_*.txt` files, counts `approve` vs others, computes
   pass-rate. Filters `.prompt.txt` (raw prompts, not JSON verdicts).
2. promptfoo eval cache (TBD — FORWARD-REF)
3. DeepEval pytest output (TBD — FORWARD-REF)

**Logic**:
- First run (no baseline) → `--baseline-update` writes baseline → exit 0
- Subsequent runs → compute current pass-rate → compare against baseline
- If `(baseline - current) > threshold` → exit 2 BLOCK
- Otherwise → exit 0 PASS

**CLI**:
```
python evals/evolve_pass_rate_gate.py [--source codex] [--threshold 0.05]
                                       [--recent-n 20] [--baseline-update]
```

**Exit codes**: 0 = pass-rate within tolerance OR baseline initialized; 1 = error
(no parseable codex reviews; baseline malformed); 2 = REGRESSION (blocking).
