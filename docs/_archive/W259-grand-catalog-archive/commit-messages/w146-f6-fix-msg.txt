## Why W146-F6 commit `82413db` shipped invalid JSON

The Edit tool's old_string was `(auto mode active).` (literal period, NO quote).
The new_string was `currently NOT set. ⚠️ ...mechanical-mirror exception (Agent C
missed gap #1 closure)."` — accidentally included trailing `"` thinking it was
inside the JSON string boundary, but the JSON string was already closed-by-
file's existing `"` after the old_string match.

Result: `closure)."` (my extra `"`) + `"` (existing JSON close) = `closure).""`
followed by `,` (field separator) — JSON parser expects `,` directly after the
closing `"` but found `"` instead = parse failure.
