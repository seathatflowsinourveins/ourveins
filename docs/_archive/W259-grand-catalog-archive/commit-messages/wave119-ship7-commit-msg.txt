### Prescription 1 (P-1): Regex silently dropped 53 of 1108 claude cache events

Pre-fix regex matched only `cache hit` and `cache miss[^|]*?` — missed `selector.go:513`
emits "cache hit but auth unavailable, reselected | ..." (53 events) AND `:523` emits
"fallback cache hit | ..." (rare).

Post-fix per codex prescription:
- Regex extends to 4-alternation (longer specifics first per regex engine left-to-right):
  `(cache hit but auth unavailable, reselected|fallback cache hit|cache hit|cache miss[^|]*?)`
- 3-bucket classifier: hit (`:503` true hit + `:523` fallback hit) / reselect (`:513` cached
  binding invalidated mid-flight) / miss (`:535` new binding)
- 3-column output table (was 2-column hit/miss; now hit/rsel/miss)
- Cache rate computed honestly: `hit / (hit + reselect + miss)` — does NOT count
  degraded reselected events as full hits

Mia probe: regex matched 1055/1108 (53 silent-drops); selector.go:503,513,523,535
verified via grep on `Z:/repos/deps/CLIProxyAPI/sdk/cliproxy/auth/selector.go @ HEAD 785b00c3`.

### Prescription 2 (P-2): Default `--since-mins 60` returns zero events

Last cache event was 8.6h old per log timestamps; default 60min window made `python
tools/cpa-cache-rate.py` (no args) return "(no session-affinity events in window)" —
misleading default UX.

Post-fix:
- `--since-mins` default 60 → 1440 (24h)
- `--lines` default 5000 → 10000 (covers 24h activity even at peak rate)

Mia probe: log timestamp probe confirms last event 02:44 / current ~11:23 = 8.6h gap.
