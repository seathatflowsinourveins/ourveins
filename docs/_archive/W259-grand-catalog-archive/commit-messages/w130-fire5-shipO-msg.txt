**Body** (verbatim): "The new `Bash(*git commit *)` and `Bash(*git push *)` patterns match the token sequence anywhere in the Bash input, not just as an executable command. From the provided context, these entries launch `codex_postcommit_review.py` and `codex_prepush_review.py`, so commands like an `echo`, comment, generated script, heredoc, or test fixture containing `git commit ...` / `git push ...` can trigger review hooks even when no commit or push happened. That can create false review artifacts against the current HEAD, introduce noisy or blocking gates in unrelated operations, and make recovery harder because the trace suggests a real commit/push path was exercised.
