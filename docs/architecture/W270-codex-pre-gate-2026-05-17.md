## §2 TOP-3 FORWARD RISKS

1. **Known Claude Code hazards remain easy to under-state.** CC-bug-#46915 still has a context-mode cache-heal workaround in the live rule layer, and W269 also warns plugin auto-update can regress patched hook paths. A W270 plan that upgrades plugins, refreshes caches, or removes workaround files needs to prove context-mode and codex hooks still load after `/reload-plugins`, not just that versions advanced.

2. **Cross-service ordering races can look like configuration failure.** Graphiti needs FalkorDB live before indexing; memory/observability producers need their chosen trace backend live before they emit; hindsight needs its local inference endpoint live before retain/recall drains backlog. Starting everything in the wrong order can create false negatives, retries, or silent no-op traces.

3. **Verification may collapse back into artifact-exists checks.** W269's dominant failure mode was declaring success because a model file existed, a service reported RUNNING, or an endpoint returned HTTP 200. W270 must verify trace-actually-flows, graph writes actually land, Cognee actually handshakes, and local inference actually generates through the selected model path.
