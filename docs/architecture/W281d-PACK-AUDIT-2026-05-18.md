## Top 5 highest-value adoption candidates

> Only one candidate emerges from the audit as a *true* new install — `planning-with-files`. The rest are either already wired (alirezarezvani/karpathy/mattpocock-overlap) or single-source / vendor-bound. Below is the full ranked shortlist with one paragraph each.

### 1. **`planning-with-files`** (OthmanAdi, 21,374★) — **ADOPT**
Manus-style persistent markdown planning fills a real gap. We currently have `everything-claude-code:plan` (ephemeral) and `superpowers:writing-plans` (writes a single PLAN.md), but neither maintains a live multi-file `.planning/` directory that the agent can read+write as the project evolves. This is the *exact* primitive that GSD-build and alirezarezvani built their entire workflows around — strong 3-source convergence. **Install path**: clone `https://github.com/OthmanAdi/planning-with-files` → install SKILL.md to `~/.claude/skills/planning-with-files/` (one-file skill, Windows-portable, no hook). **Risk**: low — pure text skill, no scripts. **Verify**: after install, run `claude /plugin list` and confirm description-match auto-fire triggers on planning tasks.

### 2. **`vercel-react-view-transitions`** — STUDY (install on-demand)
Single-source (vercel-labs) but vendor-authoritative for React 19. Defer until the operator opens a React 19 project. **No install today.**

### 3. **`vercel-react-native-skills`** — STUDY (install on-demand)
Single-source. Defer until React Native enters scope. **No install today.**

### 4. **`zoom-out`** — STUDY (cheap to add later)
Trivial skill — could be added as a standalone `~/.claude/skills/zoom-out/SKILL.md` if the operator wants an explicit perspective-lift trigger. Covered ~80% by `superpowers:brainstorming` already. **No install today.**

### 5. **`gsd-build framework` (as a research artifact)** — STUDY (treat as architecture reference)
