## Anti-patterns this wave MUST avoid

1. **Self-reinforcement** — do NOT cite our v3 rubric, sca-v3, W288 streams, or any prior local artefact as authority. Cite external (academic, multi-org practitioner, MCP-protocol-authority) sources only.
2. **One-source convergence** — every claim needs ≥3 organizationally-distinct cites.
3. **Stars-as-authority** — apply our own operator mandate to external systems: low-popularity high-quality frameworks count equally.
4. **Skipping the inverse test** — for each competitor, ask "would v3 be PATTERN-STUDY under THEIR rubric?"
