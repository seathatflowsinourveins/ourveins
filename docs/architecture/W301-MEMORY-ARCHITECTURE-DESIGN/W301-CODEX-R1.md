## Per-finding details
Q8 is the most important rubric issue. Stream C's T3 conclusion is probably directionally correct, but the arithmetic is not a valid sca-v5 replication. The sca-v5 skill defines D1 as license compatibility, D3 as harness fit, D7 as maintenance velocity, D14 as reversible pilotability, and adds D19-D21 to the active v5 install/pattern composites. Stream C instead uses an older/custom dimension map and then reports exact-looking scores. This should be revised because future waves may reuse these numbers as if they were canonical sca-v5 outputs.

Q9 is the highest-confidence technical bug. Standard ACT-R base-level activation is `B_i = ln(sum_j t_j^-d)`, with `d` commonly around 0.5. Some ACT-R literature uses an optimized approximation for evenly spaced presentations, but that approximation is not the simplified `ln(n) - d ln(L)` shown in Stream C and the synthesis. Since Cortex's "ACT-R thermodynamic decay" is one of the three transferable patterns, the design should carry the correct equation and label any engineering simplification honestly.

## Summary
The W301 design should not be blocked: the HYBRID-A+E recommendation is well supported by the internal W297/W300 trail, the two benchmark audits correctly avoid runtime adoption, and the Cortex mis-attribution correction is verified. I would not ratify the current synthesis unchanged. The top fixes are to correct the ACT-R formula and re-score Cortex with canonical sca-v5 D1-D21 rather than the Stream C lite rubric. Secondary cleanup: narrow "all 5 agentmemory scripts import src/state" to the 4 retrieval scripts, remove D16 hard-cap wording when score=2, make migration rollback fully explicit, and replace the §7 row-7 meta bucket with one concrete action. Ship-readiness after these edits: APPROVE-WITH-MINOR-NOTES.
