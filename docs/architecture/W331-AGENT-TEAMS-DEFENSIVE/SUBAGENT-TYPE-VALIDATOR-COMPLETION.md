## 3. Build Script Design — `tools/build-subagent-allowlist.mjs` (≤100 LOC)

**Trigger surface**: invoke via (a) PostToolUse hook on `/plugin install` and `/plugin update` (deferred — Anthropic CC PostToolUse hook events do not expose slash-command names per `docs/anthropic.com/en/docs/claude-code/hooks` event-schema as of W331; alternative: SessionStart hook fires on every CC boot, runs build if cache mtime > allowlist mtime); (b) manual `node tools/build-subagent-allowlist.mjs --regenerate`; (c) operator-curated cron via `tools/loop` weekly.

**Algorithm sketch** (≤100 LOC target):

```js
// tools/build-subagent-allowlist.mjs
import { readdirSync, readFileSync, statSync, writeFileSync, existsSync } from 'node:fs';
import { join, basename } from 'node:path';

const CACHE = 'Z:/claude-sota-installed/.claude/plugins/cache';
const LOCAL_AGENTS = 'Z:/claude-sota-installed/.claude/agents';
const ALLOWLIST = 'Z:/claude-sota-installed/.claude/state/subagent-type-allowlist.json';
const BUILTIN = ['Explore', 'Plan', 'Sonnet-only', 'general-purpose'];

function walk(dir, suffix) {
  if (!existsSync(dir)) return [];
  const out = [];
  for (const e of readdirSync(dir, { withFileTypes: true })) {
    const p = join(dir, e.name);
    if (e.isDirectory()) out.push(...walk(p, suffix));
    else if (e.name.endsWith(suffix)) out.push(p);
  }
  return out;
}

function extractName(mdPath) {
  // YAML frontmatter `name:` field is canonical subagent_type per CC schema
  const txt = readFileSync(mdPath, 'utf8');
  const m = txt.match(/^---\n([\s\S]*?)\n---/);
  if (!m) return null;
  const nm = m[1].match(/^name:\s*([A-Za-z0-9_-]+)\s*$/m);
  return nm ? nm[1] : basename(mdPath, '.md');
}

const agents = new Set(BUILTIN);
// Plugin-shipped agents (path: cache/<marketplace>/<plugin>/<version>/agents/*.md)
for (const p of walk(CACHE, '.md')) {
  if (p.includes('/agents/') || p.includes('\\agents\\')) {
    const n = extractName(p);
    if (n) agents.add(n);
  }
}
// Operator-curated local agents
for (const p of walk(LOCAL_AGENTS, '.md')) {
  const n = extractName(p);
  if (n) agents.add(n);
}

const out = {
  _doc: 'W326 P0-A2 + W331 P1-E rebuild. Generated by tools/build-subagent-allowlist.mjs.',
  _count: agents.size,
  _generated: new Date().toISOString().slice(0, 10),
  _sources: { plugins_cache: CACHE, local_agents: LOCAL_AGENTS, builtin_count: BUILTIN.length },
  allow: [...agents].sort()
};
writeFileSync(ALLOWLIST, JSON.stringify(out, null, 2));
process.stdout.write(`W331-build-allowlist: wrote ${agents.size} entries to ${ALLOWLIST}\n`);
```

**Drift detection**: build-script writes `_generated` timestamp; validator (future patch) reads timestamp, WARNs to stderr if >30 days stale. Per CR-1 W331 axis-1 #3 trust-tuple (d) "dependency blast-radius" — stale allowlist = cumulative drift risk.

## 4. Fuzzy-Suggestion Algorithm — Levenshtein (chosen)

**Choice**: Levenshtein distance ≤2 (insert+delete+substitute), NOT Jaro-Winkler. Rationale:
- Levenshtein handles transposition-via-2-edits cleanly (`agnt-teams` ↔ `agent-teams` = distance 2: insert `e`, delete `n`).
- Jaro-Winkler weights prefix similarity (good for human names; over-weights `team-*` prefix for our 307-entry namespace).
- Levenshtein O(m·n) on 307 candidates × typical 20-char name = ~120k cell-comparisons = sub-1ms in Node 22.

**Composite ranking** (proposed validator patch, keep current as fallback):
1. Exact lowercase match → rank 0 (return-only)
2. Levenshtein ≤2 → rank by distance ascending
3. Prefix match → rank 3
4. Substring match → rank 4
5. Cap top-3 (not top-5 per CLAUDE.md L20 spec: "fuzzy top-3 suggestions")

**Cite-anchor**: Apache Commons Text `LevenshteinDistance` — referenced impl pattern.

## 5. Soft-Fail vs Hard-Block Decision Tree (explicit)

```
event in stdin
├── parse fails or empty → exit 0 (no-op)
├── tool_input.subagent_type absent → exit 0 (no validation surface)
├── subagent_type IN BUILTIN → exit 0
├── allowlist file missing/unparsable → exit 0 + stderr WARN  ← SOFT-FAIL
├── allowlist file present + subagent_type IN allow → exit 0
└── allowlist file present + subagent_type NOT IN allow
    ├── suggest top-3 via Levenshtein ≤2
    └── exit 2 with diagnostic block + suggestions  ← HARD-BLOCK (CR-5 §b sanctioned)
```

Rationale for soft-fail on missing file (preserved from W326 ship): operator-broken-state should not brick all Agent dispatch; advisory-absent < false-positive-block on legitimate-name-typed-in-good-faith.
