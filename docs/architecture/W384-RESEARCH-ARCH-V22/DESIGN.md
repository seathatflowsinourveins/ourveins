# sca-v22 — Research-Architecture Evolution (Design)

> **The research architecture defines "SOTA" for the whole runtime** — it determines the quality of every
> downstream adoption, pattern-study, and reference. v22 evolves the shipped **sca-v21-MVP** (a pure SCORER,
> codex APPROVE@0.91, merged `ea8eccd`) into a comprehensive **discover → converge → decide → compare** engine.
>
> Synthesized from a 3-stream deep-dive (R-A discovery+ranking · R-B multi-angle-convergence · R-C
> decision-model+pathway-fit), each grounded in live deepwiki/repomix/perplexity probes of gpt-researcher ·
> STORM · dify · composio · wshobson/agents + OpenSSF/Tech-Radar/Gartner/MCDA + ~10 academic papers.
> Cross-model gate: codex GPT-5.5 (pending). **Weights stay FROZEN** (codex P0 anti-overfit) until a 50-repo backtest.

## §0 — Current state + the 3 structural gaps (verified in code)

sca-v21 = 4 CLASS-A fetchers (`github-graphql`/`depsdev`/`osv`/`scorecard`) → `Promise.allSettled` → ~16 disjoint
dims → per-class weighted-arithmetic-mean → 5-tier soft-gate (`routeTier`). Honest (`missingness` per dim;
unknown≠clean). **Three structural gaps drive v22:**
1. **No DISCOVERY layer** — discovery deferred to v21.1; today a human picks `owner/name`. (`gh-cascade.sh` exists, unwired.)
2. **Fetchers own DISJOINT dims** → zero cross-source overlap → confidence = pure `measured_ratio` → *1 source guessing == 3 sources agreeing* (`contract.mjs:195`).
3. **Confidence is computed but NEVER gates routing** — `routeTier` ignores it; a 38%-measured INSTALL and an 85%-measured INSTALL share thresholds (`contract.mjs:152` vs `:195`). Plus tier is single-axis-dominated by D13 install-path.

## §1 — DISCOVERY plane (R-A) — `tools/sota-discovery/discover.mjs` (new)

- **Shape = STORM multi-FACET fan-out** (broadens candidate coverage by construction — but completeness is only CHECKED, never *guaranteed*; see the coverage-CHECK below), NOT gpt-researcher's depth-budgeted recursion. Facets (independent retrievers, union+dedup by `owner/name`): (1) keyword/topic search, (2) reverse-dependency centrality (deps.dev/libraries.io), (3) **awesome-list mining** (curated quality pre-filter), (4) paper-linked (HF/PapersWithCode), (5) trending/star-velocity, (6) **named-anchor "alternatives-of" expansion** (scrape anchor READMEs' Alternatives/Compared-to sections). *Cite: stanford-oval/storm multi-persona; gpt-researcher SourceCurator.*
- **GitHub 1000-result-cap partitioner** (load-bearing — "claude code"=2204 truncates live): recursively halve `created:`/`pushed:` date windows + star-bucket until each slice's `total_count ≤ 1000`. *Without this, dense niches silently truncate.*
- **Dual discovery score** (single ranking axis is empirically wrong — `sort:updated`=noise, `sort:stars`=leaders): `leader_score` (reverse-deps + abs-stars + cross-source-mention-count) **and** `hidden_gem_score` (reverse-deps + **star-velocity** [from GraphQL `stargazers{starredAt}`] + recency, age/abs-stars discounted). Never rank gems on the leader axis — surfaces the operator's "high-quality-low-star" repos.
- **Query-completeness + coverage-CHECK** (NOT a landscape-completeness *guarantee* — codex r1: partitioning only proves the executed facets weren't truncated, not that every relevant repo exists): assert (a) every facet ran and each GitHub slice was non-truncated (`total_count ≤ retrieved`), and (b) a **named-anchor cross-reference CHECK** — each known anchor's README "Alternatives/Compared-to" repos appear in the candidate set; a missing one = a flagged coverage HOLE to investigate, not proof of completeness. Track which source(s) surfaced each repo (multi-source-confirmed = leader; single-niche-source = candidate-gem, NOT discarded). Emit a **candidate-leader set** + a **coverage-gap report**. Curated-list membership = positive signal, **never a disqualifier**.

## §2 — ASSESSMENT plane — multi-angle fetchers + new dims (R-A + R-B)

- **New fetchers** (close the 38-50%-measured floor): `lib/fetchers/deepwiki.mjs` (D12 docs / D14 pattern-density / D18 arch-relevance — AI-on-repo), `repomix.mjs` (D15 cite-anchor density + structural pattern evidence — pack→grep, **counts only**), `perplexity.mjs` (D19 reframe: grounded "is-this-the-leader"+recency, replaces gameable mention-count), `ecosystems.mjs` (cross-registry dependents — the second independent D21 measurement).
- **New DIMENSIONS** (R-C): **D23** data-egress/token-custody (self-host=1.0 · optional=0.6 · cloud-mandatory-token-custody=0.0→INSTALL veto — the composio blocker), **D24** dependency-blast-radius (`0.5·scorecard + 0.25·(1−log10(1+N_trans)/3) + 0.25·(1−0.2·V_known)` — the neo4j-labs blocker), **D25** adaptation-pathway-score (plugin 1.0/skill 0.9/MCP 0.6/subagent 0.4/docs 0.2/none 0.0 — extends `deriveInstallPath` + `SKILL.md` probe), **D26 Windows-compat** (`0.4·os_matrix + 0.4·win_binary + 0.2·(1−0.2·posix_flags)` — probe `.github/workflows` for `windows-latest` + repomix-grep POSIX IOCs: `/tmp`,`os.fork`,bash-only — *the genuinely-absent runtime-specific signal*).
- **OVERLAP_DIMS** (break the disjoint invariant so sources CAN converge): D21 dependents (deps.dev + ecosyste.ms + criticality), D22 CVE (osv + Scorecard-Vulnerabilities), D07 license (GraphQL SPDX + deps.dev + LICENSE-read), + the qualitative dims (deepwiki + repomix + perplexity).
- **Real CISA-KEV lookup** (R-C): replace the CVSS-critical *proxy* (`osv.mjs:117`) with the live `cisa.gov/.../known_exploited_vulnerabilities.json` feed; KEV-membership = boolean veto, CVSS-critical demoted to a score penalty.

## §3 — CONVERGENCE engine (R-B) — 3-layer fusion (the missing V21-1 intent)

- **Layer 1 — per-dim reconciliation**: agreement-test by **dim TYPE** (codex r1 — one tolerance is too blunt): **enum** (license/install-path) = exact class; **security** (KEV/CVE) = exact, any disagreement escalates (never average a CVE); **count** (dependents) = rel-tolerance `0.5`; **ratio** (coverage/density) = tight `0.2`; **qualitative** (deepwiki/perplexity) = semantic band. → credibility-weighted aggregate (`v* = Σwᵢvᵢ/Σwᵢ` numerics; weighted-majority enums) + a **convergence score κ** (≥2 agree=1.0 · single-source=0.7 · disagree=0.5→`CONFLICTING`+keep-safer-value+escalate · none=0.0). **κ does NOT change the frozen cluster weights** — it shrinks the dim's *value* toward neutral (0.5) by `(1−κ)`, a pure confidence operation (low-agreement dims contribute less decisively; the weight vector is untouched). *[codex r1: this is how the freeze stays honest — weights fixed, κ a separate evidence-confidence axis.]*
- **Layer 2 — convergence-aware confidence** (replaces measured_ratio-only): `convergence_confidence = coverage × agreement` where `agreement = Σκ_measured / measured_dims`. A 90%-coverage-but-all-single-source repo correctly drops HIGH→MEDIUM.
- **Layer 3 — conditional gpt-5.5 consensus** (synthesizer/tie-breaker, ConSensus/Roundtable pattern): fires on (a) any `CONFLICTING` dim, (b) verdict within ±0.05 boundary band, (c) CLASS-A-hard vs CLASS-B/C-qualitative tier-split, or **(d) single-source evidence on a VETO/hard-filter dim** (license / KEV / egress — high-impact even when far from a tier boundary; codex r1). Receives evidence-anchors only (SHA/values/κ — tiny), adjudicates, emits tier + confidence delta as an `operator-attestation` evidence anchor with `lineage.codex_round`. Single authoritative synthesizer beats N-agent debate (composio's no-arbitration negative result).
- **Source→role map** (DISCOVERY/ASSESSMENT/INGESTION, confidence-weighted w∈[0,1], ledger-calibrated later per ECL). **Context-protection (non-negotiable)**: fusion runs over tiny EvidenceAnchor structs; raw packs/pages die in the sandbox (repomix grep→counts; `ctx_fetch_and_index`→FTS5 summary; deepwiki→bounded answer) per the SessionStart `context_window_protection` rule.

## §4 — DECISION plane (R-C) — confidence-aware soft routing + F_fit 2-axis

- **Decision pipeline — explicit precedence** (codex r1, removes the D23 veto-vs-BLOCK contradiction): **(1) BLOCK veto** — the ONLY two true hard-gates: real-KEV-active OR verified-proprietary-license → BLOCK. **(2) Tier-ceilings** (cap the max tier, route-DOWN, NOT block): D23 unbounded-cloud-mandatory-token-custody → ceiling=PATTERN-STUDY; noassertion / restricted-copyleft license → ceiling=PATTERN-STUDY (fails the INSTALL hard-filter but can still study/cite — keep `contract.mjs:163`). **(3) Compute Q** per-class (geometric-mean soft-AND for INSTALL; arithmetic for PATTERN/CITE) **and F_fit**. **(4) Apply the confidence-aware threshold**. **(5) Route DOWN** to the highest tier whose gate passes, capped by any step-2 ceiling. So D23/restrictive-license are *ceilings*; only KEV/proprietary *block*.
- **Confidence-aware INSTALL threshold** (closes gap #3; uses the SINGLE unified `convergence_confidence` = coverage×agreement from §3 — NOT a separate `measured_ratio`; codex r1 flagged the two competing signals): `effective_install_threshold = base(0.6) + (1 − convergence_confidence)·penalty(0.25)` — a low-confidence repo needs a higher score to INSTALL, operationalizing "unknown≠clean" at the *routing* layer. Score discounted by the same signal: `effective = raw·convergence_confidence + 0.5·(1−convergence_confidence)` (shrink-to-neutral). Report `tier @ convergence_confidence-band (evidence-gaps)` + a **`path_to_higher_tier`** field ("would INSTALL if D17→exact-pins + license verified-permissive").
- **F_fit contextual-fit axis** (orthogonal to intrinsic quality Q; **modulates, never overrides** — GE-McKinsey 2-axis): `F_fit = 0.35·APS(D25) + 0.25·WCS(D26) + 0.20·LGS(D07-gate) + 0.20·DBRS(D24)`; LGS=0 (restricted) ⇒ F_fit=0. **INSTALL now requires `F_fit ≥ 0.7 AND scores.install ≥ effective_threshold`** — replaces the loose D13-only filter + the non-reproducible OpenHands "architect-veto." The (Q × F_fit) grid: High-Q/High-fit→INSTALL · **High-Q/Low-fit→PATTERN-STUDY** (the operator's case) · Low-Q→MONITOR/CITE.
- **Geometric-mean "soft-AND" for INSTALL cluster combination** (R-A): replace the arithmetic mean (`(0.9,0.9,0.01)`→0.60, masks weak dims) with `∏ clusterMeanᶜ^wᶜ` (→0.20) — one near-zero cluster drags INSTALL down hard. Keep arithmetic for PATTERN-STUDY/CITE-ONLY (compensation acceptable there).
- **Tier↔Tech-Radar ring map**: Adopt→INSTALL · Trial/Assess→PATTERN-STUDY · Assess(docs)→CITE-ONLY · Assess(volatile)→MONITOR · Hold→BLOCK. Discrete tiers force a recommendation (validates the 5-tier over a scalar).
- **MONITOR operationalized**: temporal score-drift + cessation-probability (survival model, commit-recency/contributor-churn/release-cadence features) + re-eval trigger — not a fallthrough bucket.

## §5 — COMPARISON plane (R-C) — peer-relative "X beats Y because…"

Emulate wshobson/agents `PluginEval compare`: (1) **peer-set** by capability/role → CC-install-path → dep-overlap, with **validity safeguards** (codex r1: bad grouping dominates TOPSIS/ELECTRE): min-set-size ≥3, capability-homogeneity check (reject sets mixing distinct roles), and a measured-coverage floor per criterion (don't rank on mostly-NOT_MEASURABLE dims); (2) score every peer (existing scorer); (3) emit **both** a Pareto-dominance view (X dominates Y: ≥ all, > on D20/D21/D13) **and** a scalar tiebreak via **TOPSIS** (closeness-to-ideal, cluster-weights as criteria weights) with **ELECTRE-veto** on hard-filter dims (license/egress/KEV non-compensable); (4) dim-by-dim **compare report** with per-dim winner + one-line rationale. Stars stay informational-only.

## §6 — Corrections (CR-6 verify-before-claim)

**Our prior Stream-A claimed OpenSSF Criticality uses noisy-OR `1−∏(1−xᵢ)` — WRONG.** It is a **weighted *arithmetic* mean of log-normalized signals** `C = (1/Σαᵢ)·Σαᵢ·log(1+min(Sᵢ,Tᵢ))/log(1+Tᵢ)` (deepwiki + perplexity-on-README confirm; `contributor_count` & `dependents_count` weight=2). v22 adopts geometric-mean/soft-AND **deliberately** (§4), not mis-attributed to Criticality. (Also: Criticality's default `dependents_count` = commit-mentions; our D21=deps.dev is the *more accurate* path — keep it.)

## §7 — What stays unchanged (do NOT redesign)

5-tier soft-gate (Tech-Radar-validated), per-decision-class scoring (Pareto, no single scalar), **stars informational-only** (anti-bias), honest missingness tagging, hard-BLOCK-then-route-down ordering, **FROZEN v20 cluster weights** pending the 50-repo stratified backtest (codex R1 P0) — and per codex r1, κ (§3) does NOT alter these weights; it is a separate evidence-confidence shrink on dim *values*, so the freeze stays honest. v22 = discovery + convergence + decision-defensibility + comparison, **not a rewrite**.

## §8 — Implementation routing (phased)

- **P1 — Discovery**: `discover.mjs` (multi-facet fan-out + 1000-cap partitioner + dual leader/gem score + coverage-CHECK + gap-report artifact). Reuses `lib/http.mjs` cache + missingness discipline.
- **P2 — Assessment+convergence**: new fetchers (deepwiki/repomix/perplexity/ecosystems) + D23/D24/D25/D26 dims + OVERLAP_DIMS + Layer-1/2 convergence in `contract.mjs` + the schema delta (`sca-v22` strict-superset: per-dim `convergence{κ,agreeing_sources,resolution}`, top-level `convergence_confidence`, `consensus` block). Real CISA-KEV in `osv.mjs`.
- **P3 — Decision**: confidence-aware `effective_install_threshold` + `F_fit` + geometric-mean INSTALL + `path_to_higher_tier` + Layer-3 gpt-5.5 escalation hook in `sca-evaluate.mjs` + MONITOR temporal.
- **P4 — Comparison**: `compare` subcommand (peer-set + Pareto + TOPSIS + report).
- Each phase = own characterization + golden-fixture tests (the sca-v21 test pattern); codex-gated; committed on W384. Weights frozen throughout.
