**Verdict**: **OPEN — P0** (T3 memory tier completely missing).

**Resolution path** (in priority order):

1. **Cheapest fix** (<5 min): pin `langfuse<3` in the cognee venv:
   `Z:/venvs/claude/Scripts/pip.exe install "langfuse>=2.60,<3" --force-reinstall`
   then `nssm restart CogneeMCP`. Validates: `curl http://127.0.0.1:8000/mcp` returns MCP handshake.
2. **Forward fix** (≤30 min): patch `cognee/modules/observability/get_observe.py:122` to use `from langfuse import observe` (the v3 path) and upstream a PR. Keep langfuse pinned to current v3.
3. **Last resort**: disable Langfuse callback in cognee env (`MONITORING_TOOL=NONE`), restart. Removes the import but loses cognee→Langfuse trace coverage.
