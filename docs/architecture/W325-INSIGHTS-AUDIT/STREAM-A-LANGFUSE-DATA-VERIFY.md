## §3 — Root-cause hypothesis ranking

### §3.1 Hypothesis A (HIGHEST PRIORITY) — missing `OTEL_EXPORTER_OTLP_HEADERS` for Langfuse auth

Langfuse OTel doc cite (`https://langfuse.com/docs/opentelemetry/get-started`):

> Langfuse uses [Basic Auth](https://en.wikipedia.org/wiki/Basic_access_authentication) to authenticate requests. You can use the following command to get the base64 encoded API keys (referred to as `AUTH_STRING`): `echo -n "pk-lf-1234567890:sk-lf-1234567890" | base64`.

Our `Z:/claude-sota-installed/.claude/settings.json:env` contains:
- ✅ `OTEL_TRACES_EXPORTER=otlp`
- ✅ `OTEL_EXPORTER_OTLP_TRACES_ENDPOINT=http://127.0.0.1:3000/api/public/otel/v1/traces`
- ✅ `OTEL_EXPORTER_OTLP_TRACES_PROTOCOL=http/protobuf`
- ❌ **`OTEL_EXPORTER_OTLP_HEADERS` is NOT SET** (verified by `env | grep OTEL` and direct settings.json inspection this session)

**Without auth headers, every CC-emitted trace POST gets rejected by Langfuse with HTTP 401 (unauthenticated).** The CC OTLP exporter silently drops on 401 (no retry, no log surface in CC's transcripts).

**Confidence**: HIGH — this is the canonical, documented Langfuse requirement; our config is missing it; the trace count (3 manual probes only) is consistent with this; the §1.1 probe confirms the server requires auth.

### §3.2 Hypothesis B (MEDIUM) — `x-langfuse-ingestion-version` header missing

Langfuse doc:
> If you want spans ingested directly via OpenTelemetry to appear in real time in Langfuse Cloud Fast Preview, include the `x-langfuse-ingestion-version: 4` header.

We don't set this — but on **self-hosted v3.170.0** this is optional (it controls the v4 fast-preview pipeline). Older v3 ingestion path likely works without it. Lower priority than (A).

### §3.3 Hypothesis C (LOW) — CC OTLP exporter not actually firing

We've verified `CLAUDE_CODE_ENABLE_TELEMETRY=1` is set. If the underlying CC implementation (v2.1.144) has a regression that swallows OTLP errors, we'd need raw network tracing (Fiddler/Wireshark) to confirm. Lower priority because (A) is the obvious root cause.

### §3.4 Hypothesis D (LOW) — Langfuse OTel endpoint deprecated for ingestion

Per W282-A trace-flow-verification (2026-05-18 02:53Z) the endpoint accepted a manual trace — so the endpoint itself works. Eliminates (D).
