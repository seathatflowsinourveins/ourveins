### 2.2 KV-cache (where the free VRAM is)

PR 1547 (CUDA) + PR 1556 (CPU): "Even better Q4_0 KV cache" — scale-adjusted Q4_0, **+0.37% PPL** on `Qwen3.5-35B-A3B IQ4_XS` (Table-1, ctx 8192, wiki.test.raw). PRs 1033/1034 + 1527: K/V Hadamard pre-rotation reduces quant-induced spread by another ~0.15%.

**SWITCH**: `-ctk q8_0 -ctv q4_0` → `-ctk q4_0 -ctv q4_0 --k-cache-hadamard --v-cache-hadamard`. **Frees ~2 GiB** at 64K ctx; enables ~96K ctx within budget.

### 2.3 Speculative decoding

**Status quo**: NO spec-decode currently active on :8080 (live cmdline verified).

**Candidates**:
- **MTP (Multi-Token Prediction, PR #1745/#1810/#1809 — landed 2026-05-17)**: native Qwen-MTP arch support in ik_llama. **VERIFIED: current GGUF lacks `blk.*.nextn.*` tail tensors** (gguf_dump scan = 0 hits). Two paths:
  - (a) Re-quantize from base with `--mtp-requantize-output-tensor` (PR #1809 ships the flag today)
  - (b) Pull Unsloth MTP-aware re-upload when available
- **ngram-mod (self-spec)**: PRs #1261/#1646. Recipe `--spec-type ngram-mod --spec-ngram-size-n 24 --draft-min 48 --draft-max 64`. ~16 MB shared hash pool. **NO MoESD penalty** (self-spec, no extra expert forward).
- **Draft-model spec-decode**: ❌ Tokenizer mismatch (Qwen3.6 vocab 248,320 vs off-the-shelf 152k) + MoESD penalty (−13% to −53% on A3B MoE per arxiv 2505.19645).
- **EAGLE-v3 / Medusa-2 / Hydra**: ❌ vLLM/sglang only.
- **Lookahead-decoding**: demo-only in ik_llama (`examples/lookahead/`), no server integration.

**Pick (today)**: `ngram-mod` with the MoE recipe. **Pick (after re-quant)**: MTP via PR #1810.

**W261 correction**: prior "DROP `--spec-type ngram-mod`" advice was based on misreading MoESD (which targets draft-MODEL spec, not self-spec ngram).

### 2.4 Flash attention + fused MoE

- `-fa on` — Flash Attention v2 enabled (already applied).
- `-fmoe` — Fused MoE kernel **default-enabled** in build-new (verified `--help` shows `--no-fused-moe` as the disable flag, default: enabled).
- `--merge-qkv -muge -sas` — kernel fusions applied (current).

### 2.5 Context management

- `--fit --fit-margin 1024` — auto-fit to free VRAM (applied).
- `--cache-ram 4096` — host-RAM cache offload (applied).
- `--ctx-checkpoints 8 --ctx-checkpoints-interval 512` — long-context resumability (applied).
- `--no-context-shift` — drop tokens at limit rather than slow shift (applied).

### 2.6 What ik_llama does NOT have (rule out)

No `-act-` activation-quantization flags. No FP8 K-V. No AWQ/EXL3/MARLIN kernels. No EAGLE/Medusa/Hydra. **All deliberately out of scope** — these require leaving the Windows-native ik_llama lane.
